# Features & roadmap
* Matrix → EduPage
  * [x] Message content
    * [x] Plain text
    * [ ] Formatted messages (EduPage messages are plain text)
    * [x] Files (as EduPage attachments)
    * [x] Replies (answer in the thread)
  * [ ] Message edits, deletions, reactions (EduPage has none for messages)
  * [ ] Typing notifications, read receipts (EduPage has none)
  * [x] New messages to a person
  * [ ] New messages to a class or group (only replies there)
* EduPage → Matrix
  * [x] Messages, threads as replies, your own messages
  * [x] Attachments (as links)
  * [x] Notices in the EduPage room
    * [x] Grades
    * [x] Homework with its deadline and material (text and files)
    * [x] Sign-ups with their window and your choice
    * [x] Events and other text notices
    * [x] Read confirmations, as a reply to their message
    * [x] Changed notices as edits
    * [x] Arrivals and meals (optional)
  * [ ] Removed messages
  * [ ] The timetable and substitutions (left to calendar tools)
  * [x] User metadata (names)
  * [ ] Profile photos
* Misc
  * [x] Sign-in with a password, with or without the school's name
  * [x] Second factor: confirmed in the app, or a mailed code
  * [x] Signing in again with the stored password when the session expires
  * [x] Searching teachers and starting a chat
  * [ ] Searching pupils and parents
